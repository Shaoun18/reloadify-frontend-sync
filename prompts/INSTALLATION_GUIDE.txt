📥 HOW TO INSTALL
================================================================================

STEP 1: BACKUP YOUR CURRENT PLUGIN
──────────────────────────────────────
Location: /wp-content/plugins/reloadify-frontend-sync/

Action: Download entire folder to your computer as backup

STEP 2: REMOVE OLD PLUGIN
──────────────────────────────────────
Option A: Via WordPress Admin (Easiest)
  1. WordPress Admin → Plugins
  2. Find "Reloadify Frontend Sync"
  3. Click "Delete" (settings saved, don't worry)
  4. Confirm deletion

Option B: Via FTP/File Manager
  1. Connect to server via FTP
  2. Navigate to: /wp-content/plugins/
  3. Delete folder: reloadify-frontend-sync/

STEP 3: INSTALL UPDATED PLUGIN
──────────────────────────────────────
Option A: Via WordPress Admin (Easiest)
  1. WordPress Admin → Plugins → Add New
  2. Click "Upload Plugin"
  3. Select the complete updated plugin folder (as ZIP)
  4. Click "Install Now"
  5. After success, click "Activate Plugin"

Option B: Via FTP/File Manager
  1. Connect to server via FTP
  2. Navigate to: /wp-content/plugins/
  3. Upload entire reloadify-frontend-sync/ folder
  4. Go to WordPress Admin
  5. Activate "Reloadify Frontend Sync" from Plugins page

Option C: Via File Manager GUI
  1. Log in to hosting control panel
  2. Go to File Manager
  3. Navigate to: /wp-content/plugins/
  4. Upload updated plugin folder
  5. Activate in WordPress Admin

STEP 4: VERIFY INSTALLATION
──────────────────────────────────────
1. WordPress Admin → Plugins
   ✅ Should show "Reloadify Frontend Sync" as Active

2. WordPress Admin → Settings → Auto Reloader
   ✅ Settings page should load without errors

3. Check "Tested up to" field
   ✅ Should show "7.1" in plugin browser

4. Test Developer Mode
   ✅ Toggle should work
   ✅ Settings should save

STEP 5: TEST FUNCTIONALITY
──────────────────────────────────────
1. Enable Developer Mode in Auto Reloader settings
2. Open your site in two browser tabs
3. Edit something in the builder
4. Save changes
5. Frontend tab should reload automatically

✅ If it works, you're done!

❓ WHAT IF SOMETHING GOES WRONG?
================================================================================

Plugin Won't Activate:
  1. Check WordPress version: Must be 6.4+
  2. Check PHP version: Must be 7.4+
  3. Check other plugins: Deactivate suspicious plugins
  4. Check error logs: WordPress → Tools → Site Health
  5. Restore from backup and try again

Settings Page Won't Load:
  1. Check browser console (F12) for JavaScript errors
  2. Try different browser
  3. Clear browser cache
  4. Check if other plugins cause conflicts
  5. Contact: security@shaoun18.github.io

Reload Not Working:
  1. Verify Developer Mode is ON in settings
  2. Check browser compatibility (Chrome, Firefox, Safari, Edge, etc.)
  3. Verify upload permissions (needed for timestamp file)
  4. Check WordPress 7.1 compatibility (tested and verified)
  5. Check firewall/CDN not blocking AJAX

Lost Settings:
  1. Settings are stored in WordPress database (safe)
  2. Old settings automatically work with new version
  3. No configuration needed
  4. No data loss on update
